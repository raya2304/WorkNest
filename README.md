# WorkNest — Coworking Space Website

WorkNest is a modern coworking space website that presents flexible workspaces, membership options, office amenities, and booking functionality in a clean and professional interface.

## Features

- Responsive layout for desktop, tablet, and mobile
- Modern hero section and navigation
- Workspace listings with category filters
- Membership plans with pricing cards
- Workspace details and plan selection
- Amenities and testimonials
- Interactive booking form with validation
- FAQ accordion
- Notification messages and smooth scrolling
- Professional footer with contact information

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Google Fonts
- Unsplash

## Getting Started

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the workspace cards, pricing plans, filters, and booking form.

## Project Structure

```text
WorkNest/
└── index.html
```

## Important Note

This is a frontend demonstration project. Workspace prices and testimonials are sample content. The booking form validates input and displays a confirmation preview, but it does not send requests to a server or create real appointments.
